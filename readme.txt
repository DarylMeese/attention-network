Connect your WordPress website directly to Attention Network. Manage restaurant food and drink menus directly from your WordPress admin dashboard and embed them anywhere.

== Description ==

The Attention Network WordPress plugin connects your business's website to the Attention Network platform.

= Key Features =
* **In-WordPress Menu Manager**: Create and manage menus, sections, items, modifiers, pricing, and dietary badges directly inside your WordPress admin area.
* **Bi-Directional Platform Sync**: All updates sync immediately with the Attention Network API.
* **Layouts**: Standard Restaurant Menu (classic card or list), Brewery Taplist Board (with ABV, IBU, glassware pricing), and QR Mobile Menu.
* **Gutenberg Block & Shortcode**: Embed your menu with `[attention_menu]` or visually select it using the Gutenberg Block.
* **High Performance**: Built-in WordPress transient caching guarantees fast page loads for your visitors.

== Installation ==

1. Upload the `attention-network` folder to the `/wp-content/plugins/` directory, or upload the zip file via **Plugins > Add New > Upload Plugin**.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Navigate to **Attention Network > Settings** in your WordPress admin menu.
4. Enter your Organization ID, API Base URL, and API Key (Bearer Token), then click **Test Connection**.
5. Go to **Attention Network > Food & Menus** to create and manage your menus!
6. Add `[attention_menu]` to any page or post to display your menu.
